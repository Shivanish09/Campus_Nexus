# SATI Campus Guide

A simple guide to SATI campus information, people and offices, student steps, and a guided Campus Nexus demonstration.

## What visitors can do

- Find SATI's institute location on an interactive map and open the official SATI campus photo gallery.
- Search the people and office directory; use the official contacts link for current contact details.
- Browse the student guide.
- Follow a Campus Nexus walkthrough from a sample incident through campus connections, similar cases, response comparisons, and human review.
- Ask the Campus Helper to find any of these sections or explain the walkthrough.

The Campus Nexus walkthrough uses illustrative sample data. It is not connected to live SATI sensors or dispatch systems. Response plans are drafts for human review; the demo does not send notices or dispatch resources.

## Run locally

Requirements: Node.js 20.19 or newer and npm.

```bash
npm install
npm run dev
```

Open the local address printed by Vite. To create a production bundle, run `npm run build`.
